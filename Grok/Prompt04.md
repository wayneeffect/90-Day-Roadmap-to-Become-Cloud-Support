**Here’s a practical 90-day roadmap** to become job-ready for an entry-level **Cloud Support Associate** or **Cloud Support Engineer** role (most commonly on AWS, the market leader).

This assumes 10–20 hours per week. It prioritizes **AWS**, hands-on practice, troubleshooting skills, and the soft skills that support roles demand. You can do this with little or no prior experience.

### Overview
| Phase | Days | Focus | Main Goal |
|-------|------|-------|-----------|
| 1. Foundations | 1–30 | IT basics + Cloud concepts | Solid understanding + AWS Free Tier ready |
| 2. Core Skills & Practice | 31–60 | Core AWS services + Support skills | Hands-on labs + troubleshooting ability |
| 3. Certification + Job Ready | 61–90 | Cert + Portfolio + Applications | Pass foundational cert + start applying |

---

### Days 1–30: Foundations
**Goal**: Build the non-negotiable basics every Cloud Support role needs.

1. **IT & Operating Systems Basics** (Week 1)
   - Learn how computers, servers, and virtualization work.
   - Install Linux (Ubuntu) on a free VirtualBox/VM or use free cloud shells.
   - Practice basic Linux commands (file navigation, permissions, processes, packages).
   - Free resources: freeCodeCamp Linux course, YouTube (NetworkChuck or TechWorld with Nana).

2. **Networking Fundamentals** (Week 2)
   - TCP/IP, DNS, HTTP/HTTPS, IP addressing, subnets, firewalls, VPN basics.
   - Free: NetworkChuck “Networking for Beginners” series or Cisco Packet Tracer tutorials.

3. **Cloud Computing Concepts** (Week 3)
   - IaaS / PaaS / SaaS, public vs private vs hybrid, shared responsibility model, regions & availability zones, elasticity, high availability.
   - Create a free AWS account (Free Tier) and enable MFA + billing alerts.

4. **AWS Cloud Practitioner Prep** (Week 4)
   - Study core AWS services at a high level (EC2, S3, IAM, VPC, RDS, Lambda, CloudWatch).
   - Free resources: AWS Skill Builder – “Cloud Practitioner Essentials”, AWS Educate, freeCodeCamp AWS Cloud Practitioner course.

**Daily habit**: 30–60 minutes of hands-on in the AWS console + note-taking of key concepts.

---

### Days 31–60: Core AWS Skills + Support Mindset
**Goal**: Become comfortable troubleshooting common cloud issues.

1. **Master the Core Four + Support-Critical Services**
   - Deep dive: IAM (users, roles, policies), EC2, S3, VPC (security groups, NACLs), CloudWatch, CloudTrail, Systems Manager.
   - Practice creating, configuring, monitoring, and fixing resources.

2. **Hands-on Labs & Small Projects** (do at least 8–10)
   - Host a static website on S3 + CloudFront.
   - Launch and secure an EC2 instance (SSH, security groups).
   - Set up basic monitoring/alerts with CloudWatch.
   - Troubleshoot intentional “broken” setups (e.g., wrong security group, IAM permission issues).
   - Free labs: AWS Free Tier, AWS Skill Builder labs, AWS Educate.

3. **Support-Specific Skills**
   - Learn structured troubleshooting methodology (gather info → isolate → resolve → document).
   - Practice root-cause analysis and writing clear customer responses.
   - Soft skills: Clear written communication, empathy, escalation etiquette.
   - Recommended: AWS Cloud Support Associate Professional Certificate on Coursera (Course 3 covers support best practices). You can start this series now.

4. **Optional but high-value**: Basic Python/Bash scripting for automation (simple scripts to check instance status or list S3 buckets).

---

### Days 61–90: Certification, Portfolio & Job Hunt
**Goal**: Get certified, prove your skills, and start landing interviews.

1. **Certification**
   - Pass the **AWS Certified Cloud Practitioner** exam (target by Day 70–75).
   - Cost: ~$100. Use free practice exams on AWS Skill Builder or freeCodeCamp.
   - If time and energy allow, begin studying for Solutions Architect Associate (SAA-C03) — this significantly boosts your profile.

2. **Build a Portfolio (3–5 documented projects)**
   - Document everything on GitHub + a simple personal site or Notion page.
   - Ideas tailored to Support roles:
     - “Troubleshooting guide”: Series of common AWS issues you intentionally broke and fixed (with screenshots and explanation).
     - Cost-optimized architecture for a simple web app.
     - Monitoring & alerting setup for an EC2/S3 environment.
     - IAM least-privilege policies for different user roles.
   - Write clear READMEs explaining the problem, your diagnosis steps, and the solution (this mimics real support tickets).

3. **Job Preparation**
   - Update LinkedIn and resume with keywords: AWS, Cloud Support, Troubleshooting, IAM, EC2, S3, Linux, Networking, Customer Support.
   - Highlight labs, projects, and any certification.
   - Practice common interview questions:
     - “Walk me through how you would troubleshoot an EC2 instance that can’t be reached.”
     - “Explain the shared responsibility model.”
     - Behavioral: “Describe a time you resolved a difficult customer issue.”

4. **Apply Aggressively**
   - Target titles: Cloud Support Associate, Cloud Support Engineer, AWS Support, Junior Cloud Engineer, Cloud Operations Associate.
   - Apply to 5–10 roles per week starting Day 75.
   - Use AWS Educate Job Board, LinkedIn, Indeed, company career pages (Amazon, MSPs, consultancies).
   - Network: Comment on LinkedIn posts by cloud professionals and join relevant communities.

### Recommended Free / Low-Cost Resources
- **AWS Skill Builder** & **AWS Educate** (official free courses + labs)
- **Coursera**: AWS Cloud Support Associate Professional Certificate (excellent role-specific path)
- freeCodeCamp full AWS courses on YouTube
- AWS Free Tier for real practice
- NetworkChuck, TechWorld with Nana, and freeCodeCamp for Linux/networking

### Success Tips
- Consistency beats intensity — study/practice almost every day.
- Focus more on **troubleshooting and communication** than just memorizing services (this is what separates support candidates).
- Track progress weekly (e.g., services learned, labs completed, projects finished).
- After 90 days you should be competitive for entry-level roles. Many people land their first Cloud Support job within 3–6 months of consistent effort.

Start today by creating your free AWS account and completing the first Linux basics module. Good luck — you’ve got this!
